Example 2
Write the following numerals in Roman numbers:
(a) 53 (b) 67 (c) 57 (d) 88
Solution
(a) 53 = L + III
= LIII
Therefore, 53 is LIII.
(b) 67 = LX + VII
= LXVII
Therefore, 67 is LXVII.
(c) 57 = L + VII
LVII
Therefore, 57 is LVII.
(d) 88 = LXXX + VIII
= LXXXVIII
Therefore, 88 is LXXXVIII.
