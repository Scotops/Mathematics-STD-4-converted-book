Comparing fractions using < and > symbols

Fractions with different values can be compared using the symbols < (less than) or > (greater than).

Example 1

Use the symbols < or > to compare 14 and 25.

Solution

14 is smaller than 25.

Thus, use the symbol <.

Therefore, 14<25.

Example 2

Use the symbols < or > to compare 23 and 37.

Solution

23 is greater than 37.

Thus, use the symbol >.

Therefore, 23>37.
