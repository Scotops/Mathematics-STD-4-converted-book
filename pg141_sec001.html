Addition of decimal numbers with more than one decimal place

Numbers with more than one decimal place can be added by starting with decimal parts then whole numbers.

Example 1
2.45 + 0.31 =
Steps

1.Add the decimals: 45 + 31 = 76. Write 76 in decimal place.

2.Add the whole numbers: 2 + 0 = 2. Write 2 in the whole number place.

Solution
2.45
+ 0.31
2.76

Therefore, 2.45 + 0.31 = 2.76.

Example 2
7.98 + 2.65 =
Steps

1.Add the decimals: 98 + 65 = 163. Write 63 in the decimal place. Shift 1 to the whole numbers position.

2.Add the whole numbers: 1 + 7 + 2 = 10. Write 10 in the whole number place.

Solution
7.98
+ 2.65
10.63

Therefore, 7.98 + 2.65 = 10.63.
