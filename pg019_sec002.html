Roman numbers from C to D

The Roman numbers C and D are the only representations of hundreds whereas C stands for 100, while D stands for 500. When C is written to the left of D, its value is subtracted from D; however, when C is written to the right of D, its value can only be added up to three times.

For example,

(i) CD (ii) DCC (iii) DCCC
