Example 3
Convert 1100 into decimal.
Steps
1. Divide the numerator by the denominator: 1÷100, it is not sufficient. Write 0 above the digit 1 in the answer position, then put a decimal point.
2. Multiply: 0×10=0. Write 0 below 1 then subtract: 1−0=1.
3. Write a zero in front of the 1 to make it 10, then divide: 10÷100, it is not sufficient. Write 0 to the right of the decimal point in the answer position, then write 0 in front of 10 to make it 100.
4. Divide 100 by 100 to get 1. Write 1 in the answer position to get 0.01.
5. Multiply: 1×100=100. Write 100 below 100 then subtract: 100−100=0..
